# 宏库菜单与导出整理 — 设计说明

日期：2026-08-26  
状态：已确认，待实现计划

## 背景

宏库工具栏与右键菜单项过多、含义不清；导出格式常驻在底部，且文件夹/嵌套宏导出时依赖子宏难以整包分享。上一轮已修复 `.mcrx` 导入时 `macro.call` 的 ID 重映射；本设计聚焦 **菜单精简** 与 **导出向导/文件夹打包**。

## 目标

1. 顶部只保留「新建」下拉（宏文件 / 文件夹），去掉复制、粘贴、删除按钮。
2. 右键按目标区分：宏文件 / 宏文件夹 / 空白。
3. 导出时才弹出两步向导（格式 → 可选打包方式）。
4. 导出宏文件夹时自动收集依赖子宏，可选「两个子文件夹」或 ZIP。

## 非目标

- 不重做宏库树 / Explorer 整体壳。
- 不改导入核心重映射逻辑（已有）。
- 不强制在 ZIP 内再做第三方格式转换层。

## 方案

采用 **方案 1：在现有 `MacroLibraryPanel` 上改 UI + 增加导出向导对话框**，复用现有导出与 `macro.call` 依赖解析。

## UI 行为

### 工具栏

- 仅保留「新建 ▾」按钮；菜单项：宏文件、文件夹。
- 快捷键保留：`Ctrl+N` 新建宏，`Ctrl+Shift+N` 新建文件夹。
- 复制 / 粘贴 / 删除仅通过右键与快捷键（`Ctrl+C` / `Ctrl+V` / `Delete`）。

### 右键 · 宏文件

- 复制
- 粘贴
- 删除
- 导出
- 重命名
- 锁定宏文件

移除：打开、创建副本、全选、查看、排序、刷新、新建（这些不在文件菜单中）。

### 右键 · 宏文件夹

- 导出该宏文件夹
- 复制
- 粘贴
- 重命名
- 删除宏文件夹

### 右键 · 空白

- 新建 ▸ 宏文件 / 文件夹
- 粘贴
- 查看 ▸ …
- 排序方式 ▸ …
- 刷新

### 底部导入导出区

- 移除常驻「导出格式」下拉。
- 「导出」按钮与右键「导出 / 导出该宏文件夹」均进入导出向导。
- 导入区与说明文案保持；补充「分享请带上宏文件夹 + 依赖子宏」类提示。

## 导出向导

两步向导（`ExportWizardDialog`）：

1. **选择导出格式**（默认 MacroHID MCRX）。
2. **选择打包方式**（仅当目标为宏文件夹，或导出集合需要依赖分包时显示）：
   - 两个子文件夹
   - ZIP 压缩包

随后选择保存路径（文件另存为 / 目录选择 / ZIP 文件名）。

- 单宏文件：仅第 1 步，然后另存为。
- 多选宏文件：仅第 1 步；选一个目标目录后，把所选宏写成并列 `.mcrx`。若存在夹外依赖，把依赖宏一并写入同目录下的 `依赖子宏/`（无依赖则不建）。不进入第 2 步（第 2 步仅文件夹导出）。
- 宏文件夹：第 1 + 2 步。

若格式为不完整支持 `macro.call` 的弱格式（如 MacroConverter XML）：向导给出警告，仍允许继续。

## 文件夹导出与依赖

### 收集

1. 收集目标文件夹内全部宏（含子文件夹时保持相对路径）。
2. 扫描其中 `macro.call`（含循环、条件 Then 内调用），解析库引用。
3. 不在本文件夹内的依赖宏归入「依赖子宏」集合；递归收集；环检测：跳过已访问并记入诊断。

### 输出结构

父目录或 ZIP 根下：

```text
{文件夹名}-导出/
  {文件夹名}/          # 本文件夹宏（保留相对子路径）
  依赖子宏/            # 外部依赖；若无依赖则省略该目录
```

- `.mcrx` 写入库 `id`，对方多选/整包导入时走现有重映射。
- 写盘失败：弹错误并中止；依赖解析失败：警告并继续导出已解析部分。

## 组件落点

| 组件 | 职责 |
|------|------|
| `MacroLibraryPanel.xaml(.cs)` | 工具栏、右键可见性、导出入口、去掉格式下拉 |
| `ExportWizardDialog`（新建） | 两步向导 UI |
| `MacroLibraryPanel` 导出辅助 / 小范围 helper | 收集宏+依赖、写目录或 ZIP |
| 字符串资源 zh-CN / zh-TW / en | 菜单与向导文案 |
| 测试 `Program.cs` | 菜单结构、向导步骤、文件夹导出分包断言 |

## 错误处理

- 未选中可导出目标：状态栏提示，不打开向导。
- 锁定宏：导出允许；删除/重命名仍受锁保护。
- ZIP 创建失败：提示并保留已选选项，允许改路径重试。

## 验收标准

1. 顶部无复制/粘贴/删除按钮，仅有「新建 ▾」。
2. 三类右键菜单与上文一致。
3. 底部无常驻导出格式下拉；导出走两步向导。
4. 文件夹导出可选两个子文件夹或 ZIP，且自动检出依赖子宏。
5. 对方导入后主宏 `macro.call` 能解析到子宏（`.mcrx` 路径）。
6. 既有相关测试通过，并新增本设计对应测试。

## 决策记录

- 打包方式：同时提供「两个子文件夹」与 ZIP，导出时可选。
- 导出 UI：两步向导（非一步弹窗、非纯系统另存为）。
- 文件夹右键：精简版（单删除 + 粘贴）。
- 新建：下拉按钮。
- 空白右键：保留资源管理器式菜单。
- 实现路径：方案 1（面板内改 + 向导，不抽大服务、不大改壳）。
