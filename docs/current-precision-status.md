# MacroHID 当前实现与精度验证状态

更新日期：2026-10-14。原双宏记录保留 2026-10-13 的测量口径。

最新单宏补充见 [尾部优化与真实接收实测](single-macro-tail-and-end-to-end-2026-10-14.md)：极限档固定核五轮十万事件，最大迟到对照 1,230.4µs、保留方案 893.4µs；物理热键 30 次到独立 Win32 接收窗口，中位 3.461ms、最大 8.708ms。最终版本另有 Win32/WPF 各 2,000 次自动真实输入接收，全部有效。托管回归 388 项通过。仍不能声称微秒级端到端或硬实时最大值保证。

2026-10-15 输入 API 对照（低层钩子 / Raw Input / RegisterHotKey / 轮询，以及 SendInput 各写法）的结果见 [输入 API 对照](input-api-comparison-2026-10-15.md)：合成输入下没有任何候选优于现有路径，不接入；物理按键并列组未得出结论。这不是游戏内延迟结论。

三档策略、准备缓存、共享双线程原生调度、图像缓冲优化、界面状态与验收工具已实现。本轮功能回归通过；真实热键端到端、真实 SendInput 接收延迟及游戏帧时间联合验收尚未完成。以下数据不能视为硬实时保证，也不能推广到未测试设备或游戏。

## 2026-10-14 单宏增量

## 原生调度实测

最终验证使用两个并发计划，每个 50000 个批次，1ms 节奏，每档共 100000 个有效事件。使用测试专用假输入回调，不调用真实 SendInput；预热后采样，探针申请与托管播放会话一致的 0.5ms 计时器分辨率。以下两列分位数分别对应两个计划，不是重复试验。

| 档位 | 目标 P99.9 | 计划 1 / 2 的 P99.9 迟到量 | 计划 1 / 2 的最大迟到量 | 本次调度探针 |
|---|---:|---:|---:|---|
| 均衡 | ≤250µs | 186 / 4µs | 1094 / 876µs | 达到分位数目标 |
| 极限 | ≤100µs | 2 / 2µs | 644 / 1071µs | 达到分位数目标 |

均衡两个计划的长尾差异较大；不能用较小的一列代替整体情况。毫秒级最大迟到仍存在。每档当前只有一次最终版本探针，不满足完整性能验收的重复次数和场景要求。

此前独立原生探针未申请播放会话的计时器分辨率，均衡 P99.9 为 459 / 151µs，第一路未达标，最大值为 1018 / 857µs。补齐会话条件后的前一次复测为 115 / 81µs；该次与最终版本之间还包含工作线程准备和资源生命周期修正，不能将变化全部归因于单一因素。保留这些结果用于后续复现实验，不删除未达标样本。

## 确定性瓶颈修复与微基准

| 项目 | 优化前 / 对照 | 本次结果 | 解释 |
|---|---|---|---|
| 300ms 长计划旁的 1ms 短计划 | 整段锁等待导致约 256–265ms | 均衡 1.020ms；极限 1.006ms | 批次调度消除了整计划串行阻塞 |
| 独立取消等待中的短计划 | 约 237–247ms | 两档均为 4µs | 仅本次回归样本，不是取消 P99 |
| 640×360 颜色转换分配 | 对象数组 7,372,829B | BGRA 视图 40B | 转换阶段下降超过 99%，不包含截图和识别 |
| 同一转换中位耗时 | 2359.2µs | 0.1µs | 新路径复用现有 BGRA，仅建立视图；接近计时分辨率，不应解释为完整图像处理吞吐 |

转换探针 31 次测量满足分配下降至少 85%、中位耗时下降至少 50% 的阶段目标。模板近阈值、平坦图像、像素颜色、哈希和缓冲租约回归通过；完整条件链路耗时仍需另测。

补充托管假输入探针共 1000 个样本，RunAsync 调用至首次提交的 P99 为 100µs。该探针没有覆盖真实热键回调，样本量也不足十万，仅供启动路径诊断，不作为低占用档响应验收结论。

## 尚未通过完整验收的项目

- 三档及完整主窗口路线的真实热键 P99、游戏处理延迟；极限单宏独立窗口的物理 30 次及自动真实输入接收已完成，但物理样本不足估计 P99。SendInput 返回不等于游戏收到输入。
- 三档取消请求至清理完成的十万事件 P99；当前原生取消回归验证正确性和单次耗时。
- 低占用档完整十万事件调度迟到测量；原生探针仅覆盖均衡和极限。
- 固定游戏回放下关闭宏、低占用、均衡、极限的 PresentMon 对照。尚无游戏 FPS 下降和 P99 帧时间退化结论。
- 纯播放与混合识别分别进行至少五次交替顺序、每次十分钟测试；冷启动、预热、CPU/GPU 受限、像素、模板/OCR 并发与长期运行矩阵。
- 不同设备、处理器拓扑及游戏版本的兼容性验证。本机 32 逻辑处理器结果不证明跨处理器组适用性。

同键并发回归验证宏内顺序和提交数量，不把操作系统共享的键状态改造成每宏独立设备状态。实际游戏还需检查同键冲突行为。

目标、命令、原始时间戳口径、回退开关和游戏帧时间预算见 [性能档位与验收](precision.md)。极限精度达标而游戏帧时间超预算时，仍推荐均衡；不自动更改用户选择，也不降低验收标准。
