# YSR 锁帧模块

动作面板的“锁帧模块”包含两组不同的控制方式：YSR 共享内存控制，以及现有 RTSS 锁帧。

- **YSR 开启锁帧**：默认目标 117 FPS。添加后点击序列卡片，可以修改 1–1000 的目标帧率；编辑面板也显示当前连接读取到的帧率。
- **YSR 关闭锁帧**：恢复该次开启前读取到的帧率，不需要填写恢复数值。重复开启只更新目标值，不覆盖原值。
- 播放结束、强制停止和异常清理时也会尝试恢复。尚未开启时关闭是无操作。
- 原来的 `ysr.fps.toggle` 宏仍可导入，首次切到目标值，再次切回原值。

先通过 YSR 解帧器正常启动游戏。MacroStudio 直接使用用户提供的 `fps_toggle.py` 协议：名为 `6F83E7C5-A59D-B27D-3BBE-7D67BA1B4D5B` 的共享内存，字节偏移 8 为 int32 帧率；开启期间每 50 毫秒刷新目标值。无需 Python，无需额外运行 `fps_toggle.py`，也不依赖提供源码的本机 E 盘路径。不要同时运行另一份帧率切换脚本，否则双方会反复覆盖帧率。

若显示未检测到 YSR，请先打开兼容此协议的解帧器和游戏。访问被拒绝时，使用与解帧器相同的权限运行 MacroStudio。该模块不负责启动、注入或安装解帧器，也不兼容采用其他共享内存名称/布局的版本。

关闭恢复的是开启前的原帧率，不代表把游戏帧率设成 0 或无限。当前帧率显示的是 YSR 配置上限，并非游戏实测 FPS。
