# MacroHID 2.0.2 正式版

发布日期：2026-10-15。版本号为 `2.0.2`，Git 标签为 `v2.0.2`。对比基线为测试版 `v2.0.1`，仅列出该版本之后的实际变化；`v2.0.1` 的内容一并包含在本正式版中。

## 修复

- 修复「宏基础控制」对话框点击「确定」后，默认间隔、组合键间隔、强制停止键和关闭按钮的修改不生效、重新打开又变回默认值的问题。原因是确认后从面板重新读取设置时只保留了部分字段，其余字段被默认值覆盖并写入 `MacroStudioRuntimeSettings.json`；现在以完整设置为底，只更新精度与核心掩码。

## 播放与循环

- 循环宏末尾的等待不再被丢弃。此前没有激活条件的「按下、抬起、等待 N」循环实际周期约为 10ms（按键间隔保持时长），而不是写下的 N；现在周期等于写下的总时长。每轮开始时间以上一轮起点加总时长为准，已经落后时从当前时刻开始，不追赶补发。
- 默认间隔（同一按键按下与抬起之间无延迟时的保持时间）只推迟这一次抬起，不再推迟整条时间线。「点击、等待 50、点击」不再变成相隔 60ms。同一按键再次按下会等待它自己尚未发出的抬起，其他按键不受影响。
- 组合键间隔保持原行为：之后的动作随之后移，避免「Ctrl+A、点击」变成「Ctrl+点击」。
- 播放执行器与托管控制流运行器使用同一套循环周期规则。

## 诊断

- 在 WorkerStart 与 PlanReady 之间增加三个追踪阶段，仅用于测量，不改变行为。

## 未验证与已知问题

- 本版没有重新测量热键到目标接收的端到端延迟，`v2.0.0` 的性能数据不能直接套用。
- 「宏基础控制」修复的回归测试检查的是源码结构，未做自动化界面点击验证。
- 工作区中尚未提交的原生调度改动（`SharedPlaybackScheduler.inl`、`SchedulerTests.cpp`）不包含在本版内。

下载 `MacroHID-Setup-x64.exe` 或 `MacroHID-Portable-x64.zip`，需要 .NET 8 Desktop Runtime x64。完整代码对比：[v2.0.1...v2.0.2](https://github.com/NotBadSlime/Macro/compare/v2.0.1...v2.0.2)。
