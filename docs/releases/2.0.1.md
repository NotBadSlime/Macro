# MacroHID 2.0.1 测试版

发布日期：2026-10-14。版本号为 `2.0.1`，Git 标签为 `v2.0.1`，作为 GitHub 预发布（测试版）提供。对比基线为 `v2.0.0`，仅列出该版本之后的实际变化。

## 热键入口与启动

- 前台进程名按 (窗口, 进程 ID) 缓存，热键路径每次仍重新读取前台窗口，过滤语义不变。
- 低抖动热键处于待命状态时，保持计时器分辨率请求并关闭进程电源节流，热键解除或程序退出时恢复。
- 输入安全计划随预备计划缓存；运行开始日志移到交接给执行线程之后，缩短热键到首次输入的同步段。
- 应用启动时在低优先级后台线程做一次约 40ms 的路径预热，针对冷启动首次热键的 JIT 耗时。预热不调用 Prepare，不触碰原生引擎和所选核心，界面不显示预热产生的后端与运行状态；日志每次启动会多出几行 `macro=(path warm-up)` 的开始/结束记录。

## 诊断工具（默认关闭）

- `MACROHID_HOOK_SELFTIME=1`：记录钩子回调自耗时，释放时写日志。
- `MACROHID_BATCH_TRACE=1`：原生逐批追踪，`MhpGetBatchTrace` 导出。托管侧互操作与 CSV 导出尚未接入。
- 调度基准输出增加样本数、P99.9、最大值及超阈比例。

## 未包含与未验证

- 评估后不实施或撤回：把热键处理移出钩子线程（2.2）、定向唤醒（3.1）；自旋窗口衰减（3.2）未实施。依据见 [阶段计划](../superpowers/plans/2026-10-14-scheduling-latency-phases.md)。
- 本版**没有**重新测量真实热键到目标接收的端到端数字，也没有对上述三项启动/热键入口改动做冷启动首样本的交替对照。`v2.0.0` 的性能数据不能直接套用到本版。
- 0.1–1.5ms 的调度尖峰尚未归因。托管测试 394 项通过。

下载 `MacroHID-Setup-x64.exe` 或 `MacroHID-Portable-x64.zip`，需要 .NET 8 Desktop Runtime x64。完整代码对比：[v2.0.0...v2.0.1](https://github.com/NotBadSlime/Macro/compare/v2.0.0...v2.0.1)。
