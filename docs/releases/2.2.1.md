# MacroHID 2.2.1 正式版

## 本次修复

- 单独短按 Shift、Ctrl、Alt 或 Win 时，保留宏中记录的时长。
- 按住修饰键再按另一个键或鼠标键时，才使用「组合键间隔」。例如，宏中单独按住 Shift 5 ms 时，即使组合键间隔为 30 ms，该次短按也保持 5 ms。
- 已选择 2.2.0 播放引擎的设置会自动使用 2.2.1 引擎。

## 下载

- Windows x64 安装包为 `MacroHID-Setup-x64.exe`。
- 便携包为 `MacroHID-Portable-x64.zip`。完整解压后运行其中的 `MacroStudio.cmd`。
- 文件的 SHA-256 校验值见 `SHA256SUMS.txt`。

安装包和便携包均需要 .NET 8 Desktop Runtime x64。
