# MacroHID 1.6.0

## 新增与改进

- 完善断网、内置弱网、NetLimiter 限速、RTSS 锁帧、时间偏移及后台窗口相关动作。
- 加强播放输入释放与强制停止保护。
- 隔离多宏网络和锁帧效果，避免其他播放结束时清除当前效果。
- 修复弱网积压延迟、锁帧备份丢失和系统校时后的时间恢复问题。
- 防火墙与效果恢复错误明确报告；卡片参数增加范围与空值校验。
- 卡片打开聚焦第一个文本框，Enter 确认、Alt+Enter 换行；优化关闭窗口选项布局。
- 更新宏管理、录入、条件序列及相关操作说明。

## 下载与运行

- `MacroHID-1.6.0-Setup-x64.exe`：安装包。
- `MacroHID-1.6.0-Portable-x64.zip`：完整解压后运行根目录 MacroStudio 快捷方式。

Windows 10/11 x64，需要 .NET 8 Desktop Runtime x64。断网与内置弱网需要管理员权限及 WinDivert 驱动许可；RTSS 与 NetLimiter 引擎需要各自软件运行。

348 项自动测试通过。真实网络、RTSS 和目标应用兼容性仍需按使用环境验证。发布包未签名，安全软件可能要求手动确认。
