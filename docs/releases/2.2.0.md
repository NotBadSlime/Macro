# MacroHID 2.2.0 正式版

## 更新内容

- **拖入导入 ZIP**。除了已有的普通宏文件，现在也可将导出的 ZIP 从资源管理器拖到主窗口。ZIP 内的主宏与依赖子宏会一起导入，主宏中的子宏引用会更新为导入后的引用。
- **守护宏并行运行**。在播放控制中勾选「作为守护宏运行」，即可让该宏与其他前台宏并行播放，并单独停止。可将播放模式设为「按下循环」，按一次触发键启动，再按一次停止。
- **仅运行条件序列**。即使主序列没有动作，也可以启动带动作的条件序列。循环模式会持续检查条件，直到停止播放。

守护宏和仅含条件的宏使用当前播放引擎。原来选用 2.1.0 播放引擎的配置会自动使用 2.2.0 引擎。

## 下载

- `MacroHID-Setup-x64.exe` 是 Windows x64 安装包。
- `MacroHID-Portable-x64.zip` 是便携包。完整解压后运行根目录中的 `MacroStudio.cmd`。
- `SHA256SUMS.txt` 提供安装包和便携包的 SHA-256 校验值。

安装包和便携包均需要 .NET 8 Desktop Runtime x64。 [完整改动对比](https://github.com/NotBadSlime/Macro/compare/v2.1.0...v2.2.0)
