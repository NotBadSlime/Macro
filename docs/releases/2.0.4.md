# MacroHID 2.0.4 测试版

发布日期：2026-10-18。版本号为 `2.0.4`，Git 标签为 `v2.0.4`，作为 GitHub 预发布（测试版）提供。对比基线为测试版 `v2.0.3`。

## 播放版本切换器

- 播放版本有了单独的窗口：左侧「全局运行」里新增「播放版本」按钮，标签显示当前版本（旧版本为橙色）。窗口左边是版本列表，右边逐条列出所选版本改了什么。可选 2.0.4（当前）、2.0.2、2.0.1、2.0.0、1.6.0、1.5.0、1.4.1、1.3.0 / 1.4.0、1.2.0。
- 「精度控制」改为「精度模式」「热键与发送」「CPU 核心」三张卡片，说明文字精简，不再需要滚动。
- **旧版本运行的是当时的原始代码**，不是在新代码里模拟。每个旧版本的播放代码（Core、Runtime、原生引擎）从对应的 git 标签原样取出，编译成独立的程序集和原生库，放在 `MacroStudio\legacy\` 下。宏的解析、计时、原生引擎、条件监视、子宏调用，以及热键的切换、按住、单次逻辑都由所选版本自己的代码执行，当时的问题也一并保留。
  - 1.3.0 与 1.4.0 的播放代码完全相同，合为一项。
  - 发布前用脚本把每个快照与标签逐个文件比对，确认一致。唯一的改动是 1.2.0–1.6.0 中一处标明的外部卡片接入点（3 处），以及 1.6.0 补上了当时未提交进 git 的同一个 WinDivert 驱动。
- **新功能保留**：
  - 所选旧版本没有的效果卡片（断网、弱网、限速、调时、锁帧、YSR 帧率、窗口激活），在它的时间线运行到这一步时由当前版本执行，运行结束时由当前版本恢复。
  - 测核、核心选择器、系统延迟检查始终使用当前版本，选出的核心掩码按所选版本当时的方式使用。
  - 界面、宏库、热键检测保持当前版本。
- 旧设置文件中的「精度代数」会自动迁移为对应的播放版本。
- 2.0.3 中的「1.6.0 精度代数」模拟已由真正的 1.6.0 代码取代。

## 并行卡片移除，同一时间只运行一个宏

- 动作面板中不再有并行卡片。旧宏里已有的并行卡片仍能打开和编辑，但开始监听或运行时会提示删除（所有播放版本都适用）。
- 一个宏正在运行或停止时，其他宏的热键会被忽略，「立即运行」也会被拒绝。正在运行的宏自己的热键照常能停止它，强制停止键照常有效。

## 未验证与已知问题

- 没有用真实按键在游戏中做端到端测试。每个旧版本都用不发送按键的宏验证过：单次运行、切换循环开始与停止、按住循环松开即停止，以及外部效果卡片的接入。
- GitHub 上 1.3.0 的安装包是 2026-09-21 重新上传的，代码接近 1.4.0；9 月上旬的中间构建没有对应的标签，未包含在内。
- 等文字卡片在 1.6.0 之前的版本中无法使用。宏里有这类卡片时，开始运行会提示改选更新的版本。
- 「热键启动对齐」「SendInput 耗时补偿」只对当前版本生效。
- 托管测试 422 项通过，原生调度回归测试通过。

下载 `MacroHID-Setup-x64.exe` 或 `MacroHID-Portable-x64.zip`，需要 .NET 8 Desktop Runtime x64。完整代码对比：[v2.0.3...v2.0.4](https://github.com/NotBadSlime/Macro/compare/v2.0.3...v2.0.4)。
